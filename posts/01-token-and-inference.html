01AI 學徒筆記

AI 是怎麼「說話」的？
——token 與接龍推理

我的本業是科技產品與投資，不是機器學習——但我發現只要真的搞懂一件事——「這台機器的本質是接龍」——AI 為什麼強、為什麼會一本正經地胡說、為什麼這麼燒錢，就全都說得通了。這是系列的第一篇：它到底是怎麼說話的。

學徒筆記系列・第 1 篇｜閱讀約 10 分鐘

一開始之前：token 是什麼，為什麼整個系列從它講起

先回答一個很多教學直接跳過的問題：token 到底是什麼、我為什麼要在意它？

可以這樣想：食物的世界裡有一個你看不見、但一切都用它計算的單位——卡路里。你吃的是飯和菜，但熱量、代謝、減肥計畫，全部用卡路里算。AI 的世界裡也有這樣一個單位，就叫 token。你打給 AI 的是字，但在它的世界裡，讀進來的量、寫出去的量、記得住的量、你要付的錢，全部用 token 計算。用多少 token 計費、記憶容量是多少 token、每秒能吐多少 token——它是 AI 世界的公分和公斤。

所以這個系列的第一課就是它。搞懂 token 是什麼、AI 怎麼用它「說話」，後面的一切——為什麼 AI 會一本正經地胡說、為什麼這麼燒錢、為什麼聊久了會忘記前面說過的話——就全都有了地基。

二模型從來沒有「看過字」

你打給 ChatGPT 或 Claude 的是文字，但模型從頭到尾沒有看過字。輸入的第一步，是把文字切成一段一段的 token——可以想成模型的積木：常見的英文單字通常一塊積木就是一個字，長字會被切成幾塊，中文則大多一～兩個字一塊。

token 切法與編號為示意，非任何真實模型的實際值。重點是：模型的世界裡只有「編號的序列」，沒有字、沒有詞、沒有句子。

每個模型都帶著一本固定的字典（詞彙表），通常十幾萬塊積木。字典是訓練前用統計方法從海量文字裡「學」出來的：越常出現的片段，越有資格自成一塊。這就是為什麼英文常見字一塊搞定、罕見字被剁碎——也是為什麼同樣意思的中文通常比英文花更多 token：字典是以英文為大宗的語料練出來的，中文的「壓縮率」天生比較差。

API 按 token 計價，所以這不只是冷知識——同樣的內容，中文使用者付的帳單就是比較貴。比例隨模型字典不同而異。

切完、編號完之後，每個編號會再被換成一長串數字（術語叫向量），意思相近的 token 在數字上也相近——「國王」和「皇帝」在模型的空間裡是鄰居。這是它能「理解」語意的基礎：相似的意思，被放在相近的位置。

三推理＝接龍：一次只吐一個 token

所謂「推理（inference）」，就是模型回答你的整個過程。它的核心動作簡單到令人意外：看著目前為止的所有 token，猜下一塊積木是什麼。猜完，把它接上去，再猜下一塊。如此重複，直到吐出一個代表「說完了」的特殊 token。你看到答案一個字一個字冒出來，不是打字特效——它真的就是這樣一塊一塊生出來的。

「猜」是什麼意思：一張機率表

溫度：抽籤時的膽子大小

從機率表選下一塊的方式有一顆可以調的旋鈕，叫溫度（temperature）。白話說，它就是抽籤時的膽子：溫度調低，幾乎永遠拿最高分的那塊——答案穩定、保守，適合查資料、寫正式文件；溫度調高，偶爾會抽到分數較低的——答案有變化、有驚喜，也更容易出軌，適合腦力激盪、想標語文案。

你平常用的 ChatGPT 或 Claude 介面通常沒有讓你調溫度，但你其實一直感受得到它的存在：同一個問題問兩次，答案不會一模一樣——因為每一輪都在抽籤。哪天你用 API 自己接 AI 做工具時，溫度就是手上第一顆可以轉的旋鈕：要它當嚴謹的查表員，調低；要它當點子王，調高。

等等——「接龍」怎麼會變成「推理」？

講到這裡，最多人卡住的地方是：一次猜一塊積木的接龍，怎麼可能解數學、寫程式、分析財報？關鍵在它是拿什麼練的：幾乎整個網路的人類文字。人類寫下的文字本身就充滿因果與邏輯——「因為」後面接「所以」、「3+2=」後面接「5」、程式碼每一行都有嚴格規則。要把「接得順」練到極致，模型就被迫把這些規律內化成自己的一部分。接得夠好，看起來就像會想。

對模型來說，「5」不是按計算機算出來的，而是「接在這裡最順的一塊」——但要讓 5 永遠比 4 和 6 順，訓練時它就必須真的把加法的規律內化。像不像「思考」見仁見智；接得準不準，決定它能不能用。

這也解釋了一個你可能聽過的技巧：要求 AI「先一步一步想，再給答案」為什麼有效。回到桌面的比喻——它每猜一塊，只能看桌上已經有的東西。讓它先把推理過程寫出來，等於把中間步驟一塊一塊攤到桌上，後面的接龍就有據可依；直接逼它跳到最終答案，就像要求你心算跳過過程，出錯機率自然高。現在許多模型內建的「思考模式」，本質上就是把這件事自動化。

它的記憶：只有這張桌面

模型每輪能「看著」的範圍叫上下文視窗（context window）——想成一張桌面，你的問題、之前的對話、它已生成的答案全攤在上面。桌面有大小上限，而且這個上限一直在長大：到 2026 年中，主流旗艦模型（GPT、Gemini、Claude）多已來到 100 萬 token 的等級——粗略換算是幾十萬字的中文，塞得下好幾本長篇小說。不過「標稱裝得下」和「真的用得好」是兩回事：實測顯示桌面堆得越滿，模型找東西的準頭通常會下降。關鍵是：桌面就是它的全部記憶。對話結束桌面一收，什麼都不留；下次對話它「記得你」，是因為系統偷偷把舊對話重新攤回桌上，不是它腦中真的存了你。

本篇一句話

推理＝「看全桌 → 出機率表 → 抽一塊 → 接上去」的無限重複。它不是先想好整段話再說——它說到哪、想到哪，而且每說一塊都要重新看一次全桌。
